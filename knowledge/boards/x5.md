# RDK X5 平台知识

> 资料核对日期：2026-08-10。适用于 RDK X5 与 RDK OS 3.x；具体能力以实机板型、系统版本和载板版本为准。

RDK X5 基于 Sunrise 5，官方产品规格为 8 核 Cortex-A55（最高 1.5 GHz）、4GB/8GB
LPDDR4 与 10 TOPS BPU。开发板提供双 4-lane MIPI CSI、千兆网口、USB 3.0、HDMI、
CAN FD 与 40-pin GPIO；具体模组或载板接口仍需核对对应硬件版本。

X5 使用 RDK OS 3.x 文档线。3.4.1 对齐 X5 SDK 1.1.1，重点更新启动稳定性和媒体链路。
3.5.0 起 Python 算法推理与示例统一转向 `hbm_runtime`。因此在 3.4.1 上看到旧接口并不
表示安装损坏，也不要把 3.5.0 示例原样复制到 3.4.1。

模型部署应选择 X5/Bayes 目标和与板端 `libdnn` 匹配的 OpenExplorer 工具链。官方
Model Zoo 建议转换环境与板端运行库保持更新且相互匹配；从别的 BPU 平台复制 `.bin`
或只修改文件名不能建立兼容性。

排查摄像头或媒体链路时，先用当前 RDK OS 随附的官方样例验证单路输入，再确认 sensor
配置、MIPI lane、像素格式和输出分辨率。X5 产品规格中的 4K 编解码峰值不能替代实际
pipeline 测量。

系统升级后，官方发布说明要求用 `rdk-miniboot-update` 处理匹配的 miniboot；这是高风险
写操作，只能在核对当前/目标版本、稳定供电、官方升级说明和回滚条件后执行。禁止为了
匹配旧示例而降级出厂 miniboot。
