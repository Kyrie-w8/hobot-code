# RDK S100 平台知识

RDK S100/S100P 官方硬件规格包括 6 核 Cortex-A78AE、4 核 Cortex-R52+ MCU、Mali-G78AE
GPU 与 Nash BPU；不同型号提供 80 或 128 TOPS，内存常见为 12GB 或 24GB LPDDR5。
不能只用“S100”名称推断具体算力、内存或载板版本，必须读取实机信息。

S100 使用 RDK OS 4.x 文档线。算法工具链存在明确映射：V3.2.0 对应系统软件
4.0.2–4.0.4，V3.7.0 对应 4.0.5。对于 `4.0.5-Beta`，可把 4.0.5 资料作为候选，但在
转换、驱动和多媒体接口上必须通过板端包版本与 smoke test 再确认。

4.0.5 官方发布基线为 Ubuntu 22.04、Linux 6.1.158-rt58、U-Boot 2022.04、交叉工具链
11.3 和 OE 3.7.0，并包含 BPU 频率及相机/sensor 配置变化。若实机内核或包版本不同，
优先相信实机，不要为追平文档直接批量升级。

模型转换选择 Nash 目标；提交工具链问题时提供目标硬件、`horizon_nn`、Python、Docker
镜像、ONNX、配置和完整日志。S100 Python 多媒体可使用 `hobot_vio.libsrcampy` 的
Camera、Encode、Decode 和 Display 对象，但要先确认当前镜像确实预装相应包。
