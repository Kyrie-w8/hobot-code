# RDK S600 平台知识

> 资料核对日期：2026-08-10。适用于 RDK S600 与 RDK OS 5.x；共享的 S 系列文档不等于 S100 产物可直接复用。

RDK S600 基于 Sunrise S600。官方产品规格为 18 核 Cortex-A78AE（最高 2.0 GHz）、
6 核 Cortex-R52+ MCU、4 个 Nash BPU 核心（最高 560 TOPS）、Mali-G78AE GPU，以及
32GB/64GB LPDDR5。存储、接口与载板配置按具体模组和 Developer Kit 核对。

S600 使用独立的 RDK OS 5.x 和 S600 文档线。即使 S100 与 S600 共用一部分 S 系列文档，
也不能默认复用 S100 的 4.x 工具链、镜像、驱动包或模型产物。先读取 `/etc/version`，
再从带 S600 与对应版本参数的官方资料进入。

S600 有两个 VDSP 核心；官方 VDSP 文档说明 VDSP1 仅适用于 S600/双核平台。使用第二核
前仍需确认固件、驱动、内存和示例版本，不要仅凭硬件规格直接创建生产任务。

官方峰值 BPU 和编解码数据用于容量规划，不代表单模型或任意 pipeline 的持续性能。
验收要记录模型精度、批量、输入尺寸、BPU 核心调度、板端内存、端到端延迟、功耗与温度。

S600 多媒体开发优先从当前镜像的 `/app/multimedia_samples` 建立基线，再组合 Camera、
VIN、ISP、PYM、GDC、编码和显示。跨版本复制配置时尤其检查 sensor、内存池与连续物理
内存需求。

当前官方资源线提供 RDK OS 5.1.0、S600 硬件资料、MCU Cluster-1 资源和 S 系列 OE 3.7.0
入口。工具链页面出现 `s100-s600` 包名，不等于所有模型仓库、示例和系统包都已适配 S600；
例如 `rdk_model_zoo_s` 当前 README 明确列出的主要目标是 S100/S100P，使用 S600 前必须查阅
对应模型目录和当前发布说明。不要把 S100 4.0.5 的系统包、驱动或启动配置装到 S600。

TROS 多媒体示例在 S600 上对应 Ubuntu 24.04 + ROS 2 Jazzy，常见环境入口为
`/opt/tros/jazzy/setup.bash`。从 X5/S100 Humble 项目迁移时，同时检查 ROS 发行版、依赖包、
消息/QoS、共享内存传输和 launch 参数，不能只解决编译错误。

S600 同时包含 A 核、R 核、BPU、GPU、VDSP 和媒体单元。跨核任务需要明确固件、内存归属、
缓存一致性、超时和故障恢复；通用 Agent 不应直接进入车辆或机器人的硬实时闭环。
